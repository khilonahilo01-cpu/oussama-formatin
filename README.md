## خطوات الإطلاق

### 1. قاعدة البيانات — Supabase

**أ. أنشئ المشروع**

1. افتح https://supabase.com واصنع حساباً (مجاني) ثم **New project**
2. اختر منطقة قريبة (Frankfurt أو Paris) واحفظ كلمة سر قاعدة البيانات

**ب. أنشئ الجدول والحماية**

Supabase → **SQL Editor** → **New query** → الصق محتوى ملف `supabase.sql` كاملاً → **Run**

**ج. أنشئ حساب دخولك للوحة**

**Authentication → Users → Add user → Create new user**
البريد `ousssamaformation@gmail.com` + كلمة سر قوية، وفعّل **Auto Confirm User**.

**د. 🔴 أغلق التسجيل العمومي — خطوة أمنية إجبارية**

**Authentication → Sign In / Providers → Email** → أطفئ **Allow new users to sign up**.

بدون هذه الخطوة أي شخص يقدر ينشئ حساباً ويقرأ أسماء وأرقام هواتف كل زبائنك.

**هـ. المفاتيح — ✅ موضوعة مسبقاً**

مشروعك مربوط في `script.js` و `admin.js`:

```js
supabase: {
  url: 'https://ldqohbckqnmpvfglgdje.supabase.co',
  publishableKey: 'sb_publishable_…'
},
```

> مفتاح `publishable` عمومي ومكشوف عمداً في الصفحة — هذا طبيعي ومصمَّم كذلك. الحماية تأتي من سياسات RLS في `supabase.sql`: الزائر يقدر **يرسل** طلباً فقط، والقراءة والتعديل والحذف تتطلب دخولاً بحسابك.
>
> 🔴 لا تضع أبداً مفتاح `sb_secret_…` في هذه الملفات — ذاك يتجاوز كل الحماية.

### طرق بديلة لاستقبال الطلبات (غير مستعملة)

الكود يدعم طريقتين أخريين عبر تبديل `delivery` في `script.js`:

| القيمة | الشرح |
|---|---|
| `'netlify'` | نماذج Netlify — تحتاج تفعيل **Form detection** من تبويب Forms ثم إعادة نشر. لا تشتغل محلياً. |
| `'web3forms'` | بريد مباشر — يحتاج مفتاحاً مجانياً من https://web3forms.com (250 طلب/شهر) في `web3formsKey`. |

في كل الحالات: إذا فشل الإرسال (انقطع أنترنت الزائر مثلاً)، الصفحة تعرض له رسالة صفراء تطلب التأكيد عبر واتساب حتى لا يضيع الطلب.

### 3. ادفع التعديلات إلى GitHub

```bash
cd /Users/mac/oussama-course && git add -A && git commit -m "وصف التعديل" && git push
```

Netlify يشوف الدفعة ويعيد النشر وحده خلال أقل من دقيقة.

جذر المستودع هو نفسه جذر الموقع — ما فيش مجلد نشر منفصل، فما تنساش تنسخ حتى ملف.

## قائمة التحقق قبل الإطلاق

- [x] مفاتيح Supabase موضوعة في `script.js` **و** `admin.js`
- [x] رقم واتساب حقيقي في `CONFIG.whatsapp`
- [ ] `supabase.sql` شُغّل، وحساب الدخول أُنشئ، و**التسجيل العمومي مُطفأ**
- [ ] طلب تجريبي من الموقع الحيّ ظهر في اللوحة
- [ ] `RESULTS` فيها نتائج حقيقية أو `[]` تماماً — لا تنشر نصوصاً نموذجية
- [ ] صورة `assets/og.jpg` بمقاس 1200×630 لمعاينة الرابط في واتساب وفايسبوك

## عند أي تعديل بعد النشر

زد رقم `?v=1` إلى `?v=2` في `index.html` (سطري `styles.css` و `script.js`) حتى يأخذ الزوار النسخة الجديدة بدل النسخة المحفوظة في متصفحهم.

## لوحة التسيير

`admin.html` — تخدم من **أي جهاز**: هاتفك، حاسوبك، أو من الموقع المرفوع.

الدخول ببريدك وكلمة السر اللي أنشأتهما في Supabase — لا توجد كلمة سر مكتوبة في الكود.

كل تعديل (الحالة، الملاحظة، الحذف، الإضافة اليدوية) يُحفظ مباشرة في قاعدة البيانات. الجلسة تتجدد وحدها، وإذا فشل أي حفظ ترجع اللوحة للحالة السابقة وتنبّهك بدل ما تكذب عليك.
